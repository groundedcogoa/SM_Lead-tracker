Mobile-first lead tracking app for the Sai Marketing team.  
Built by Grounded Co.

---

## Setting Up on GitHub Pages

Follow these steps exactly. Takes about 10 minutes.

---

### Step 1 — Create a GitHub account

1. Go to **github.com**
2. Click **Sign up**
3. Enter your email, create a password, choose a username (e.g. `saimarketing`)
4. Verify your email address

---

### Step 2 — Create a new repository

1. Once logged in, click the **+** icon in the top-right corner
2. Select **New repository**
3. Fill in:
   - **Repository name:** `lead-tracker` (or any name you like)
   - **Description:** Sai Marketing Lead Tracker *(optional)*
   - Set to **Public** ← this is required for free GitHub Pages
   - **Do NOT** tick "Add a README file"
4. Click **Create repository**

---

### Step 3 — Upload the file

1. On the new repository page, you'll see a prompt. Click **uploading an existing file**
2. Drag and drop **`index.html`** from your computer into the upload area
3. Scroll down to **Commit changes**
4. Leave the default message as-is
5. Click **Commit changes**

---

### Step 4 — Enable GitHub Pages

1. In your repository, click **Settings** (top navigation bar)
2. In the left sidebar, scroll down and click **Pages**
3. Under **Source**, click the dropdown that says `None`
4. Select **main** (or `master` if that's what shows)
5. Leave the folder as `/ (root)`
6. Click **Save**

---

### Step 5 — Get your live URL

1. Wait about 60–90 seconds
2. Refresh the Pages settings page
3. You'll see a green banner:  
   **"Your site is live at `https://yourusername.github.io/lead-tracker/`"**
4. Click the link to confirm it opens correctly

This is the URL you share with the team. Bookmark it on everyone's phone as a home screen shortcut.

---

### Adding it to the home screen (iPhone)

1. Open the URL in **Safari** (must be Safari, not Chrome)
2. Tap the **Share** icon (box with arrow at the bottom)
3. Scroll down and tap **Add to Home Screen**
4. Name it `Sai Marketing` → tap **Add**

It will appear as an app icon on the home screen.

---

### Adding it to the home screen (Android)

1. Open the URL in **Chrome**
2. Tap the **three-dot menu** (top right)
3. Tap **Add to Home screen**
4. Name it `Sai Marketing` → tap **Add**

---

## Updating the app in future

When you need to make changes (new team member, new PIN, new field):

1. Go to your repository on github.com
2. Click on **`index.html`**
3. Click the **pencil icon** (Edit) in the top right
4. Make your changes
5. Scroll down → click **Commit changes**

The live URL updates automatically within 1–2 minutes. No redeployment needed.

## Notes

- The app connects to Google Sheets via the existing Apps Script URL — this works fine from GitHub Pages, no changes needed
- Data is stored in your Google Sheet, not on GitHub
- GitHub only hosts the interface (the HTML file)
- The repository being Public does NOT expose your sheet data or PINs to anyone who doesn't have the URL
